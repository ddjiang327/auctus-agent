选择一个通信渠道进行配置。后续新增渠道只需要加入新的选项和配置面板。
配置 Telegram Bot
步骤：
1. 在 Telegram 搜索 @BotFather，发送 /newbot 创建 Bot
2. 复制 BotFather 给你的 Token（格式：123456:ABC-…）
3. 给你的 Bot 发一条任意消息，然后点"获取我的 ID"
4. 点"保存并测试"，手机会收到确认消息
WebSocket 长连接模式：Auctus 会主动连接飞书开放平台，不需要公网地址。
1. 在飞书开放平台创建企业自建应用并启用机器人
2. 在「事件订阅」选择「使用长连接接收事件」
3. 订阅 im.message.receive_v1，并开通接收/发送消息权限
4. 发布或安装应用后，把 App ID 和 App Secret 填到这里
当前接收模式：WebSocket 长连接。Webhook 地址仅作为高级备用：http://127.0.0.1:8000/webhook/feishu
WebSocket 长连接模式：Auctus 会主动连接 Lark Open Platform，不需要公网地址。
1. 在 Lark Developer Console 创建应用并启用 Bot
2. 在 Event Subscriptions 选择 Long Connection / WebSocket
3. 订阅 im.message.receive_v1，并开通接收/发送消息权限
4. 发布或安装应用后，把 App ID 和 App Secret 填到这里
配置 Discord Bot
步骤：
1. 前往 discord.com/developers/applications 创建应用，进入 Bot 页面
2. 开启 Message Content Intent、Server Members Intent
3. 复制 Bot Token，粘贴到下方，点"验证 Token"
4. 给你的 Bot 发一条私信，然后点"获取我的 ID"
5. 点"保存并测试"，你会收到一条确认私信

第 1 步：选择模型接入方式
使用自己的 API Key 适合个人开发者：你提供 OpenAI/Anthropic/DeepSeek 等 Key，本地保存。
本地模型 适合离线/隐私：例如 Ollama。无需云端 Key（但需要你本机已安装模型）。
Auctus 托管 API 适合小白：无需配置 API Key，登录账号即可使用。支持套餐订阅 + 余额计费。
